{{- /* Figura (imagem + legenda). O autor escreve markdown; o HTML do protótipo (.media-figure + modificador de posição) sai daqui. {{< figure src="demo/crt-monitor.jpg" alt="Monitor CRT âmbar exibindo o cursor no prompt READY." cap="Um C64 recém-ligado, antes de qualquer fita carregar." pos="inline-right" w="320px" >}} Parâmetros: src (obrig.) resource em assets/, resource do page bundle, ou URL/caminho cru alt (obrig.) texto alternativo — pode ser "" p/ imagem puramente decorativa, mas o parâmetro precisa EXISTIR: a ausência é sempre um esquecimento, e um alt faltando é o erro de a11y mais comum que existe. Por isso falhamos o build em vez de aceitar. cap (opc.) legenda visível pos (opc.) inline-left | inline-right | break-full | break-box (default: break-full — ocupa a coluna, sem float, que é o comportamento menos surpreendente) w (opc.) largura da mídia p/ inline-* e break-box (ex.: "320px") */ -}} {{- $src := .Get "src" | default "" -}} {{- if not $src -}} {{- errorf "shortcode figure (%s): falta o parâmetro obrigatório `src`" .Position -}} {{- end -}} {{- if not (isset .Params "alt") -}} {{- errorf "shortcode figure (%s): falta o parâmetro obrigatório `alt`. Use alt=\"\" se a imagem for decorativa." .Position -}} {{- end -}} {{- $pos := .Get "pos" | default "break-full" -}} {{- $valid := slice "inline-left" "inline-right" "break-full" "break-box" -}} {{- if not (in $valid $pos) -}} {{- errorf "shortcode figure (%s): pos=%q inválido.
