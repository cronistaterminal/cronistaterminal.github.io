{{- /* Figura (imagem + legenda). O autor escreve markdown; o HTML do protótipo (.media-figure + modificador de posição) sai daqui. {{< figure src="demo/crt-monitor.jpg" alt="Monitor CRT âmbar exibindo o cursor no prompt READY." cap="Um C64 recém-ligado, antes de qualquer fita carregar." pos="inline-right" w="320px" >}} Parâmetros: src (obrig.) resource em assets/, resource do page bundle, ou URL/caminho cru alt (obrig.) texto alternativo — pode ser "" p/ imagem puramente decorativa, mas o parâmetro precisa EXISTIR: a ausência é sempre um esquecimento, e um alt faltando é o erro de a11y mais comum que existe. Por isso falhamos o build em vez de aceitar. cap (opc.) legenda visível pos (opc.) inline-left | inline-right | break-full | break-box (default: break-full — ocupa a coluna, sem float, que é o comportamento menos surpreendente) w (opc.) largura da mídia p/ inline-* e break-box (ex.: "320px") */ -}} {{- $src := .Get "src" | default "" -}} {{- if not $src -}} {{- errorf "shortcode figure (%s): falta o parâmetro obrigatório `src`" .Position -}} {{- end -}} {{- if not (isset .Params "alt") -}} {{- errorf "shortcode figure (%s): falta o parâmetro obrigatório `alt`. Use alt=\"\" se a imagem for decorativa." .Position -}} {{- end -}} {{- $pos := .Get "pos" | default "break-full" -}} {{- $valid := slice "inline-left" "inline-right" "break-full" "break-box" -}} {{- if not (in $valid $pos) -}} {{- errorf "shortcode figure (%s): pos=%q inválido. Use um de: %s" .Position $pos (delimit $valid ", ") -}} {{- end -}} {{- /* Resolver a imagem como RESOURCE (assets/ ou page bundle): aí conhecemos as dimensões reais e emitimos width/height, o que reserva o espaço antes do byte chegar e mata o layout shift. Um caminho LOCAL que não resolve é FALHA DE BUILD, não um fallback. Já aconteceu: um build cuspiu src="demo/crt-monitor.jpg" (relativo, 404 em /posts/…/) enquanto o asset existia — e o site foi para o disco com a imagem quebrada, sem um aviso sequer. Emitir o src cru nesse caso é transformar um erro de build numa imagem morta em produção. Só passa sem resolver o que é EXPLICITAMENTE externo (http…) ou já absoluto (/…). */ -}} {{- $img := resources.Get $src -}} {{- with .Page.Resources.GetMatch $src -}}{{- $img = . -}}{{- end -}} {{- $externo := or (hasPrefix $src "http") (hasPrefix $src "/") -}} {{- if and (not $img) (not $externo) -}} {{- errorf "shortcode figure (%s): não achei o resource %q (procurei em assets/ e no page bundle). Se for imagem externa, use a URL completa." .Position $src -}} {{- end -}}
